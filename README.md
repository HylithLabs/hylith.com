# Hylith - Next-Gen Scroll Animated Website ✨

Welcome to the open-source repository for the Hylith agency website. Built with cutting-edge web technologies, this project stands as **one of the best scroll-animated websites on the internet**. It demonstrates complex GSAP animations, seamless scroll-triggered interactions, and a beautiful, meticulously crafted dark theme interface.

## 🚀 Features

- **Advanced Scroll Animations**: Powered by GSAP and ScrollTrigger, featuring pin sections, horizontal scrolls, and dynamic text reveals.
- **Fluid & Responsive Design**: Seamlessly adapts to any screen size without compromising the intricate animation timelines.
- **Modern Tech Stack**: Built on React and Vite for lightning-fast HMR and optimized production builds.
- **Tailwind CSS**: Rapid and maintainable styling with custom configuration for our unique design system.
- **Interactive UI Elements**: Custom cursors, magnetic hover states, and immersive responsive video backgrounds.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Hosting/Deployment**: Ready for Vercel, Netlify, or any static host.

## 💻 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hylithLabs/hylith.com.git
   cd hylith.com
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🗺️ Roadmap & Things to Do

We are open-sourcing this to the community to share our animation techniques and build upon them together. Here are some exciting things on our radar:

- [ ] **Performance Optimization**: Implement advanced asset lazy loading to improve initial load time for heavy media files.
- [ ] **Accessibility (a11y) Improvements**: Ensure all scroll animations gracefully fallback and respect `prefers-reduced-motion` queries.
- [ ] **WebGL Integration**: Introduce Three.js integrated backgrounds for even more immersive 3D interactions.
- [ ] **Dynamic Content Architecture**: Connect the site to a Headless CMS (like Sanity or Strapi) for easier portfolio updates.
- [ ] **Automated E2E Testing**: Add Cypress or Playwright for visual regression testing of our scroll timelines.
- [ ] **Component Library**: Extract the core scroll animation components into an installable npm package.
