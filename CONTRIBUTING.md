# Contributing to Hylith

First off, thank you for considering contributing to Hylith! It's people like you that make open source such a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our Issues tab to see if it's already being discussed.

## Ground Rules

- Ensure cross-browser compatibility for all GSAP animations.
- Create issues for any major changes and enhancements that you wish to make. Discuss things transparently and get community feedback.
- Keep feature requests focused on the scope of the project.

## Development Setup

1. Fork the repo and create your branch from `main`.
2. Run `npm install` to get the dependencies.
3. Make your changes in a new git branch.
4. Test your changes locally using `npm run dev`.
5. Ensure your code is properly formatted.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. The PR will be merged once you have the sign-off of other developers.

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
